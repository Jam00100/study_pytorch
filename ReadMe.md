# Study PyTorch

本 Repository 用來記錄我重新學習 PyTorch 的過程。

過去曾接觸過 PyTorch，但對部分觀念與實作流程還不夠熟悉，因此目前透過 Kaggle 題目重新複習，並逐步加深對機器學習與深度學習實作的理解。

> 持續學習與更新中。

## 學習內容

* PyTorch 基本操作
* Tensor 與資料前處理
* Dataset 與 DataLoader
* 模型建立、訓練與驗證
* 模型保存與載入
* 測試資料推論
* Kaggle Competition 實作
* 機器學習與深度學習相關方法

## Repository Structure

不同的 Kaggle 題目與練習內容會分別存放在獨立資料夾中。

每個資料夾包含該題目的說明、資料處理方式、模型架構、訓練流程與實驗結果。詳細內容請參考各資料夾內的 README。

## Environment

依照執行環境使用不同的運算裝置：

* NVIDIA GPU：CUDA
* Apple Silicon：MPS
* 其他環境：CPU

## Note

本 Repository 主要作為個人學習紀錄，部分程式與筆記仍會持續修改及整理。

Kaggle 資料集不會直接上傳至 Repository。如需執行程式，請先從對應的 Kaggle Competition 頁面下載資料，並依各專案說明設定資料路徑。
